# nlp-spam-detection
Spam detection using NLP and machine learning with Streamlit interface
# Features
- Loads and preprocesses text data for spam detection
- Performs text cleaning (lowercasing, punctuation removal, stopword removal)
- Applies NLP techniques such as tokenization and stemming
- Converts text into numerical features using TF-IDF Vectorization
- Trains machine learning models for classification (Spam / Not Spam)
- Evaluates model performance using accuracy metrics
- Provides real-time prediction using Streamlit web interface
- User-friendly UI to input custom messages and detect spam instantly
